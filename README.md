# REMOCAR 3D

لعبة سباقات سيارات ثلاثية الأبعاد تعمل كتطبيق ويب وAndroid عبر Capacitor. تتضمن شاشة دخول تحمل هوية المطوّر، وواجهة رئيسية بأيقونة ورسمة سباق مخصصتين، ومرآباً ذا معاينة ثلاثية الأبعاد قابلة للدوران مع تخصيص اللون والنقوش والصورة واللوحة العربية، ومضامير منفصلة للفردي والجماعي، وكاميرا قيادة خارجية وداخل قمرة السيارة، وتحكماً باللمس ولوحة المفاتيح. اسم المتسابق قابل للتعديل من الملف الشخصي ويحفظ على الجهاز.

صور الملصقات تُضغط إلى صورة صغيرة وتُخزن محلياً في المتصفح/الجهاز عبر Local Storage؛ لا تُرفع إلى خادم اللعبة.

## تشغيل نسخة الويب

```bash
npm ci
npm run dev
```

ثم افتح عنوان Vite الذي يظهر في الطرفية.

## اللعب الجماعي عبر Wi‑Fi

اللعب الجماعي يستخدم الآن اتصالات WebSocket فعلية، وليس محاكاةً بين تبويبات المتصفح. شغّل الخادم على حاسوب موصول بنقطة Wi‑Fi نفسها:

```bash
npm ci
npm run lan:server
```

تطبع الطرفية عنوان الشبكة المحلي للخادم، مثل `ws://192.168.1.10:3001`. اسمح باتصالات TCP على المنفذ `3001` في جدار حماية الحاسوب، مع إبقاء الحاسوب والأجهزة على شبكة موثوقة وخاصة. داخل اللعبة، أدخل عنوان الخادم؛ ينشئ المضيف غرفة ويشارك رمزها، ويختار مضماراً من مضامير الجماعي الأربعة، ثم ينضم اللاعبون الآخرون ويبدأ المضيف السباق للجميع. الخادم يعمل محلياً ولا يحتاج إلى خدمة سحابية أو إنترنت، لكنه يجب أن يبقى قيد التشغيل أثناء اللعب. عنوان الخادم يُحفظ على الجهاز.

> خادم Wi‑Fi مناسب للشبكة المحلية فقط. لا تعرّض منفذه للإنترنت العام. اللعب عبر الإنترنت يحتاج إلى استضافة آمنة تدعم WSS وإعدادات نشر إضافية.

## إنشاء APK تجريبي

يدعم التطبيق Android 7.0 (API 24) وما بعده، ويُستحسن الاختبار على أجهزة فعلية متعددة لأن أداء WebGL يختلف حسب الجهاز. يتطلب بناء APK Node.js وJDK متوافقاً مع Gradle. أنشئ أصول الويب ثم زامنها مع Capacitor وابنِ حزمة Android:

```bash
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

ينتج ملف الاختبار في `android/app/build/outputs/apk/debug/app-debug.apk`. هذا **APK تجريبي موقّع تلقائياً بمفتاح debug مخصص للاختبار، وليس بمفتاح إصدار للنشر التجاري**؛ يلزم إعداد مفتاح توقيع release وبناء نسخة إصدار قبل توزيعه على نطاق واسع أو رفعه إلى Google Play. يمكن تثبيته على جهاز موصول بـADB باستخدام `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظة الرسوم

المضامير والمركبات الحالية مجسمات Three.js إجرائية مطوّرة داخل المشروع؛ تتضمن تفاصيل هندسية وإضاءة وخامات ورسومات بيئة محسّنة، لكنها ليست نماذج سيارات مرخّصة أو أصولاً فائقة الواقعية من مستوى ألعاب AAA. الوصول إلى ذلك المستوى يتطلب إدراج نماذج GLB/GLTF عالية الجودة وخامات وبيئات مرخّصة واختبار أداء على أجهزة Android المستهدفة.
