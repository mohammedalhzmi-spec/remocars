# REMOCAR 3D

لعبة سباقات ثلاثية الأبعاد للويب وAndroid مبنية بـReact وThree.js وCapacitor. تضم أسطولاً من 19 سيارة، بينها سيارة concept مرخّصة عالية التفاصيل مع نموذج إجرائي احتياطي، و12 مضماراً فردياً و5 مضامير LAN، وبطولات مسيرة أصلية وقفزات واستعراضات هوائية. تتضمن مرآباً ثلاثي الأبعاد قابلاً للدوران وتخصيصات طلاء، ونظام مستويات وترقيات ومدربات سباق عربيات بأصوات تُفتح تدريجياً.

## أهم الميزات

- **سباق 3D:** 12 مضماراً فردياً بإضاءة وبيئات ومسارات مختلفة، 4 منها تتضمن منحدرات وقفزات ولفة هوائية قابلة للتحكم، مع مكافآت نقاط وعملات وحفظ الحركة في الإعادة. زوايا كاميرا متعددة، قمرة قيادة، ونيترو.
- **المرآب والسيارات:** أسطول 19 سيارة، معاينة ثلاثية الأبعاد قابلة للدوران للسيارة المحددة، ورسوم جانبية تفصيلية لسيارات المجموعة، ونموذج Khronos CarConcept مع بديل إجرائي، وتخصيص الطلاء والأنماط والملصق واللوحة.
- **تقدم ومكافآت:** مستويات وXP وألقاب ونجوم وعملات وفتح تدريجي للمضامير؛ تزداد صلابة اللاعب عند مستويات التقدم.
- **بطولات المسيرة:** ثلاث كؤوس فردية تعمل دون إنترنت، بثلاث جولات مرتبة لكل بطولة، ومستويات فتح ومكافآت نهائية من العملات والنجوم.
- **ميزة REMOCAR — صدى الزمن:** بعد أول لفة يرسم ظلّ ضوئي شفاف خط قيادتك السابق؛ تزامن معه عند ثلاث بوابات مضيئة لشحن اندفاع زمني تلقائي وهالة سيان ومكافأة 80 عملة. بيانات المسار محفوظة ضمن إعادة السباق.
- **ترقيات ذات أثر داخل السباق:** المحرك يحسن السرعة والتسارع، الإطارات تزيد الثبات والتحكم وتخفف فقد السرعة خارج الطريق، النيترو يرفع القوة والسعة والمدة، والهيكل المدعم يزيد تحمل الصدمات.
- **صدمات ومعززات:** الاصطدامات تستهلك التحمل وتُنهي الجولة عند بلوغ الحد المعروض؛ المستوى وترقية الهيكل يرفعان هذا الحد. معززات مضيئة على المضمار تعيد شحن النيترو وتدفع السيارة للأمام.
- **إعدادات اللعب:** اختيار توجيه الأزرار أو إمالة الهاتف مع ضبط الحساسية، تغيير حجم أزرار السباق، كتم الصوت، واختيار جودة متوازنة أو وضع أداء للأجهزة الأقدم. عجلة التوجيه يسار الشاشة، والدواسات والنيترو والاستعراض يميناً.
- **مدربات السباق:** سارة من المستوى 1، دانا 5، ريم 10، وليان 15؛ لكل منهن صورة وصوت افتتاحي ونصائح، ويتيح المستوى فتح مدربة أكثر خبرة.
- **بطولة Wi‑Fi فعلية:** 2–6 لاعبين على الشبكة المحلية، من جولة واحدة أو 3 أو 5 جولات، مع ترتيب ونقاط تراكمية (25، 18، 15، 12، 10، 8)، إعلان الفائز وإدارة بدء الجولة التالية من المضيف.
- **Android:** يبدأ التطبيق ويدور دائماً إلى الوضع الأفقي مع إخفاء أشرطة النظام أثناء اللعب؛ مشهد السباق يملأ الشاشة بلا تضخيم السيارة أو اقتطاع عناصر التحكم. عجلة التوجيه يساراً، والتسارع والفرامل والنيترو يميناً. الحد الأدنى Android 7.0 / API 24، وهدف البناء SDK 36.

## اللعب الجماعي عبر Wi‑Fi

### الاستضافة من هاتف Android

1. صِلوا جميع الأجهزة بالشبكة نفسها أو بنقطة اتصال الهاتف المضيف. يجب تفعيل نقطة الاتصال من إعدادات Android أولاً؛ لا يغيّر التطبيق إعدادات الشبكة نيابةً عن النظام.
2. يختار المضيف إنشاء غرفة واستضافة السباق؛ يبدأ التطبيق خادم WebSocket محلياً على الهاتف.
3. يبحث اللاعبون الآخرون عن الغرف القريبة ثم ينضمون. يمكن استخدام عنوان IP ورمز الغرفة يدوياً إذا حجب الموجّه بث الاكتشاف.
4. يختار المضيف المضمار وعدد الجولات ويبدأ البطولة، ثم يبدأ الجولة التالية بعد اعتماد نتائج الجميع.

يستخدم الاكتشاف UDP على المنفذ `3002` والسباق WebSocket/TCP على المنفذ `3001`. بعض نقاط الاتصال أو الموجّهات تعزل العملاء عن بعضهم؛ عندها جرّبوا شبكة أخرى أو الإدخال اليدوي. بعد إغلاق اللعبة أو الخروج من البطولة يتوقف مضيف Android.

### تشغيل الخادم على حاسوب

```bash
npm ci
npm run lan:server
```

تطبع الطرفية عنواناً محلياً مثل `ws://192.168.1.10:3001`. أدخل العنوان في اللعبة واسمح باتصالات TCP على المنفذ `3001` ضمن شبكة خاصة موثوقة. على Android يمكن الانضمام إلى غرفة الحاسوب بالبحث أو بعنوان IP ورمز الغرفة؛ واجهة الويب غير Android تستخدم عنوان الخادم والرمز يدوياً. تحقّق من الخادم عبر `http://127.0.0.1:3001/health`.

> خادم Wi‑Fi محلي وليس خادماً للإنترنت العام. لا تفتح المنفذ على الإنترنت؛ اللعب عبر الإنترنت يحتاج بنية مستضافة وآمنة تدعم WSS.

## بناء APK

المتطلبات: Node.js، JDK 21، Android SDK/Build Tools، وGradle عبر wrapper المضمّن.

### APK تجريبي

```bash
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

المخرج: `android/app/build/outputs/apk/debug/app-debug.apk`.

### APK Release موقّع

لا تحفظ المفتاح أو كلمة المرور في Git. عيّن متغيرات البيئة التالية من مخزن آمن (واستخدم **المفتاح نفسه لكل تحديث مستقبلي**)، ثم ابنِ:

```bash
export REMOCAR_RELEASE_STORE_FILE=/secure/path/remocar-release-key.jks
export REMOCAR_RELEASE_STORE_PASSWORD='from-your-secure-secret-store'
export REMOCAR_RELEASE_KEY_ALIAS=remocar3d-release
export REMOCAR_RELEASE_KEY_PASSWORD="$REMOCAR_RELEASE_STORE_PASSWORD"
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleRelease
```

المخرج: `android/app/build/outputs/apk/release/app-release.apk`. فقدان المفتاح أو كلمة مروره يمنع توقيع تحديثات متوافقة مع النسخة المنشورة. إذا كان على الهاتف إصدار debug موقّع بمفتاح مختلف، فقد يلزم إزالته قبل تثبيت إصدار Release؛ إزالة التطبيق قد تمسح بياناته المحلية.
